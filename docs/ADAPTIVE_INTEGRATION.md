# Response integration and selected domains

Ordinary calculations retain numerical values and disclose finite-domain and convergence assumptions. The canonical policy is ORDINARY_CALCULATION_POLICY.md. Uniform grids remain the default, including existing thread/MPI execution.

`UniformIntegration(region_quadrature=:left_endpoint)` selects half-open `i/N` nodes on an explicit finite `IntegrationDomain` or public Integral `KRegion`, with unchanged equal weights and normalization. Default midpoints and existing BZ grids retain their behavior. The region stays at its declared origin; this option does not translate it or supply a boundary correction.

## Adaptive response backend

Use `ExecutionOptions(fourier_backend="direct", integration_algorithm= HAdaptiveCubature(atol=0.0, rtol=1e-5, max_evaluations=100000, initial_divisions=2))`. The current `BZMesh` and `KRegion` support 1D/2D/3D sampling. Active integration axes come from mesh length or region dimension, independently of the Cartesian response tensor axes. Inactive fractional BZ coordinates are zero; a lower-dimensional mesh does not claim a three-dimensional BZ integral.

Eligible Integral responses expose the same worker-owned point providers used by regular integration and point/slice collection. Adaptive sampling is selected by the consumer, including retained SC/IC/SHG/THG/BCDC/BCQC paths and eligible q=0 spin, Projector/Geometric/Wilson current, JC and finite-temperature linear/orbital Integral providers. The registry, actual point capability and model/operator prerequisites still apply; a shared sampler supplies no missing physical operator or basis capability. The localized metric scope is described in [NONORTHOGONAL_LOCALIZED.md](NONORTHOGONAL_LOCALIZED.md). Shared dispatch does not establish independent qualification for every model family. All admitted adaptive evaluators retain their positive finite temperature, finite widths and q=0 requirements. Nonorthogonal THG remains unimplemented. HCubature.jl 1.8.0 supplies deterministic h-adaptive integration under its MIT license: 7/15 Gauss–Kronrod in 1D, Genz–Malik in 2D/3D. It uses 15/17/33 nodes per initial box. The complete initial partition needs `rule_nodes * initial_divisions^dimension` evaluations and must fit the budget. A final complete two-box refinement can exceed max_evaluations by at most 29/33/65 nodes in 1D/2D/3D. Counts and termination are retained.

The domain/evaluator/algorithm interface accepts a complex scalar or fixed-shape numeric tensor. All frequencies, Cartesian components, terms and formulations share a maximum-absolute-complex-entry norm. Tolerances apply to the consumer-declared tensor supplied to cubature. SC/IC, SHG/THG and the spectral/current consumers use their retained physical density conventions. BCDC/BCQC retain the original moment tensor before the later physical measure and DC contraction; their atol is a moment-tensor tolerance, not a conductivity error bound. Responses can be extremely small in SI. Embedded estimates are numerical estimates, never strict error bounds or scientific qualification. Budget exhaustion warns and retains the value, estimate, evaluation count and termination in integration_diagnostics.txt.

The one-rank route retains the original serial HCubature entry. With MPI, one Julia thread per rank evaluates nodes of one rule concurrently. Rank zero owns the unchanged adaptive tree, global budget and stopping decisions; owned node results are replayed through the original numerical rule in its original arithmetic order. The first physical node establishes result storage without repeating evaluation. Subsequent packets use a bounded one-GiB default transport workspace; an explicit internal pending-memory override retains its existing bounded-packet tests. The Mixed-FFT environment limit applies to Fourier caches and does not cap Direct point scratch or cubature packets. Checked storage estimates supplement the external process RSS guard. Node IDs retain deterministic round-robin owners. This controller adapter is qualified against the pinned HCubature 1.8.0 implementation and rejects a different version. Concurrency does not by itself establish a speedup: small rules, cheap kernels, communication and idle ranks can dominate.

No adaptive symmetry reduction is claimed; a supplied symmetry artifact is reported as unused. There is no automatic Fermi/resonance probe, peak detector, or mandatory repeat-grid correctness gate. User-directed refinement and material/reference comparisons remain possible. Distributional T=0/delta limits and simultaneous refinement of multiple tree boxes remain unsupported.

`integrate_response(evaluator, IntegrationDomain(lower=(...), upper=(...), coordinates=:fractional or :cartesian), algorithm; normalization=:integral or :domain_average)` separates coordinate measure from model normalization and symmetry multiplicity. `IntegrationDomain2D` remains an alias for `IntegrationDomain{2}`. Cartesian coordinates are inverse Angstrom. Mutable scratch tensors are copied before retention. Response consumers retain their declared value convention and domain average; actual BZ fraction or continuum measure enters once at the existing physical normalization boundary. Padding inactive coordinates with zero does not add an integration axis or Jacobian.

## Cartesian selected regions and Direct evaluation

KRegion uses 1–3 Cartesian axes in inverse Angstrom. ModelInput, RealSpaceTBInput, AnalyticKInput and NonorthogonalLocalizedInput retain their existing supported response families and model periodicity. KRegion currently uses Direct evaluation. Auto records effective Direct; explicit Mixed is rejected with a request to select Direct/Auto. Domain geometry, coordinate measure and response evaluator remain separate. Complete BZ and original KSlice Mixed execution retain their existing contracts. No region super-grid, subset FFT, partial-axis expansion, NUFFT/CZT or artificial supercell is used.

Analytic finite-q and derivative stencils must stay inside the declared model evaluation domain, which may exceed the integration region. Periodic regions use the original-cell prefactor and original BZ fraction. Reference reciprocal measure is the first vector length, first two-vector area, or cell volume for 1/2/3 active axes. Cartesian regions are unfolded: crossing multiple BZs can repeat contributions; there is no folding, clipping or deduplication. Nonperiodic analytic models use d^d k/(2pi)^d with corresponding SI units. Complete legacy 3x3 nonperiodic declarations retain their original continuum measure. New direct 1D/2D inputs retain their physical integration dimension and use the completed one-Angstrom reference cell for bulk coefficients; auxiliary directions add no rule nodes or budget. JC/THG no longer accept response-layer sheet/effective-bulk selectors; converting periodic results and absolute tolerances belongs to postprocessing.

Finite-domain/integration-by-parts boundary assumptions are warned and the existing formulas computed. No boundary correction is included. Users assess truncation and contributions outside the region. Patches can partition the same integrand; formulas related by integration by parts need not agree separately on each patch.

Primary backend source: https://github.com/JuliaMath/HCubature.jl/tree/v1.8.0

## Shared point and grid execution

Response physics produces worker-private point tensors or compact observation channels. `ResponseGridConsumer` owns regular-grid coordinate lookup, the prepared Fourier request and the destination sink; the adaptive consumer owns domain coordinates, rule nodes and weights. Current slice collection applies no mesh-count weight. Cell/SI normalization remains response-specific, and local geometry and orbital moments are not reinterpreted as conductivity. Band/group/transition definitions, physical widths, occupations and tensor permutations remain independent of the sampling algorithm. See the [local slice normalization](../USER_GUIDE.md#local-slice-normalization) before reconstructing an integral.

# Native model definition encoding

New operation declarations use nested `model_definition.schema = wanniernlqg.native-model-definition/2`. Native definitions encode type module/name/parameters structurally; they do not use Julia display aliases or execute callbacks. Actual matrices, parameters, captures, units/conventions and source-lifetime checks remain complete. Generic `write_native_definition_value` frame/mask consumers retain their historical default; only native model writers explicitly select the stable encoding.

The operations JSON schema remains2.0. Nested definition/1 continues through the historical exact encoding and full-byte comparison. A failed old comparison remains a rejection with an explicit re-publication hint, not a claim that only formatting differed. Recreate a new declaration from the authoritative live model and operations through `write_native_response_symmetry`; retain the old publication. Never edit just the nested schema/header, evaluate stored source text, or normalize arbitrary strings inside opaque definition bytes. Changing actual values by one ULP, capture values or source lifetime still rejects. No artifact schema grants qualification.

# Security policy

## Supported version

Security fixes are considered for the latest public release.

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue. After the public
repository is created, use its private GitHub Security Advisory reporting
channel. Until that channel exists, retain the report privately and do not
attach sensitive input data to public discussions.

Scientific-correctness reports that do not expose credentials or private data
may use the normal issue template after the public repository exists.
